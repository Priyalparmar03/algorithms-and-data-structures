# algorithms-and-data-structures

Structured DSA practice — not just solved problems, but documented engineering: problem statement, approach, complexity analysis, implementation, and tests for every entry. Built to demonstrate CS fundamentals as concrete, checkable evidence alongside coursework.

## Structure

```
algorithms-and-data-structures/
├── arrays/
├── linked-lists/
├── trees/
├── graphs/
├── hashing/
├── sorting/
├── searching/
├── recursion/
├── dynamic-programming/
└── TEMPLATE.md
```

Each topic folder contains one subfolder per problem, e.g. `arrays/two-sum/`, with:

```
problem-name/
├── README.md        # problem, approach, complexity
├── solution.py       # implementation
└── test_solution.py  # tests
```
